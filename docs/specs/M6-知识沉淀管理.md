## 1. 范围与依据

**范围**：FAQ 自动挖掘、审核发布、Redis 缓存同步、知识缺口识别与一键建档。

**依据**：
- 《PRD》§2.9.3 知识沉淀管理页、§2.9.9 FAQ 挖掘与审核发布规则、知识缺口识别规则
- 《概要设计》§5.3 FAQ 沉淀闭环、§5.4 知识缺口识别、§6 FAQ 阈值 / 缺口阈值
- 《数据对象》§5.1 faqs（含 unit_updated_at_snapshot）、§5.2 knowledge_gaps
- 《接口约定》§7.6 知识沉淀
- 《原型设计》§8.6 FAQ 与知识缺口

**非目标**：
- LLM 自动挖掘答案（演示期仅挖问题不挖答案）—— 留待 P4 后续
- FAQ 多语言 / 翻译
- 用户投票 / 反馈优化推荐

## 2. 模块概览

```
[APScheduler daily 02:00]
   │
   ▼
FaqMiningService
   1) SELECT questions + COUNT(*) FROM qa_access_logs 近30天
   2) embedding → 内存聚类（频次 ≥ 3 + 相似度 ≥ 0.80）
   3) 关联 Top-3 unit_ids → 草拟 INSERT faqs (status=pending_review, source_type=auto_mined)
   │
   ▼
[知识管理员] 审核页 → FaqReviewService.approve() / reject()
   │
   ▼ approve
FaqCacheService
   HSET faq:cache:<hash> {answer, related_unit_id, unit_updated_at}
   │
   ▼
GapDetector（每次 M4 record_log 后触发）
   │
   ▼ 召回 Top-1<0.5 且 Top-3 均 <0.55
KnowledgeGapService.record()
   │
   ▼ 缺口聚合
[知识管理员] 一键建档 → M3 KnowledgeUnitService.create() + 回填 resolved_unit_id
```

### 5.4 FaqMiningService（APScheduler 每日 02:00）

```python
class FaqMiningService:
    SIMILARITY_THRESHOLD = 0.80
    MIN_FREQ = 3
    WINDOW_DAYS = 30

    async def run(self) -> int:
        # 1) SELECT question, COUNT(*), recalled_unit_ids_json FROM qa_access_logs
        #    WHERE created_at > NOW() - INTERVAL 30 DAY GROUP BY question
        #    HAVING COUNT(*) >= MIN_FREQ
        # 2) 对每条 question 调 embedding_service.embed(question) → vector
        # 3) 内存聚类：向量两两 cosine；聚合频次 ≥ MIN_FREQ 且相似度 ≥ 0.80 的问题
        # 4) 每个聚类选 Top-3 unit_ids（按单元被召回次数）
        # 5) INSERT faqs (status='pending_review', source_type='auto_mined', related_unit_id=Top1)
        #    跳过 question_hash 已存在的
        # 6) 返回本次新增数
```

### 5.6 GapDetector（M4 调用）

```python
class GapDetector:
    """单例无状态；被 M4 record_log 节点调用"""
    async def detect(self, log_record: QaAccessLogRecord) -> None:
        recalled = json.loads(log_record.recalled_unit_ids_json or "[]")
        await self._gap_service.record(
            session_id=log_record.session_id,
            user_id=log_record.user_id,
            question=log_record.question,
            recalled_units=recalled,
        )
```

### 5.7 APScheduler 启动

```python
# app/infrastructure/scheduler.py
def start_scheduler(faq_mining: FaqMiningServiceDep) -> AsyncIOScheduler:
    scheduler = AsyncIOScheduler()
    scheduler.add_job(
        faq_mining.run,
        CronTrigger(hour=2, minute=0),
        id="faq_mining_daily",
        replace_existing=True,
        misfire_grace_time=3600,
    )
    scheduler.start()
    return scheduler
```

## 8. 异步与适配器

| 项 | 描述 |
| --- | --- |
| APScheduler | AsyncIOScheduler；每日 02:00 触发 `faq_mining_daily` |
| Embedding | 复用 M3 OpenAI client（faq_mining 需要 embed 问题） |
| Redis | `faq:cache:<sha1(question)>` HSET；`auth:bitmap` 不在本模块维护 |
| LLM 摘要 | faq_mining 暂不调 LLM，仅挖问题；答案由人工填写 |
