## 5. 后端设计

### 5.1 路由

**路由前缀**：所有端点统一 `/api/v1/<domain>` 前缀，详见接口约定文档 §7 各模块接口分组清单。

| Method | 完整路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/v1/dashboard/metrics` | `dashboard:read` | 核心五项指标；`range=7d\|30d\|90d`，默认 7d |
| GET | `/api/v1/dashboard/rankings/questions` | `dashboard:read` | 常见问题 TOP 20；`range=` |
| GET | `/api/v1/dashboard/rankings/units` | `dashboard:read` | 知识热度 TOP 20 |
| GET | `/api/v1/dashboard/stats/tokens` | `dashboard:read` | Token 趋势；`range=7d\|30d` |
| GET | `/api/v1/dashboard/stats/response-time` | `dashboard:read` | 响应时间趋势；`range=7d\|30d` |

### 5.3 Repository SQL 草案

```sql
-- metrics
SELECT
    COUNT(*)                       AS access_count,
    COUNT(DISTINCT user_id)        AS unique_users,
    COALESCE(SUM(total_tokens), 0) AS total_tokens,
    COALESCE(AVG(response_time_ms), 0) AS avg_response_time_ms
FROM qa_access_logs
WHERE created_at > NOW() - INTERVAL ? DAY;

SELECT COUNT(*) FROM knowledge_units WHERE status = 'active' AS unit_count;

-- question rankings
SELECT question, COUNT(*) AS c, MAX(created_at) AS last_asked_at
FROM qa_access_logs
WHERE created_at > NOW() - INTERVAL ? DAY
GROUP BY question
ORDER BY c DESC
LIMIT ?;

-- unit rankings（JSON 展开）
SELECT ku.id AS unit_id, ku.unit_code, ku.title, COUNT(*) AS access_count
FROM qa_access_logs qa
JOIN knowledge_units ku
  ON JSON_CONTAINS(qa.recalled_unit_ids_json, JSON_OBJECT('id', ku.id), '$')
WHERE qa.created_at > NOW() - INTERVAL ? DAY
GROUP BY ku.id, ku.unit_code, ku.title
ORDER BY access_count DESC
LIMIT ?;

-- token stats（按日分桶）
SELECT
    DATE(created_at) AS bucket_date,
    SUM(total_tokens)     AS total_tokens,
    SUM(prompt_tokens)    AS prompt_tokens,
    SUM(completion_tokens) AS completion_tokens
FROM qa_access_logs
WHERE created_at > NOW() - INTERVAL ? DAY
GROUP BY DATE(created_at)
ORDER BY bucket_date;
```

export const dashboardApi = {
  metrics: (rangeDays: 7 | 30 | 90) =>
    api.get<MetricsResponse>("/dashboard/metrics", { params: { range: `${rangeDays}d` } }).then(r => r.data),
  questionRankings: (rangeDays: 7 | 30) =>
    api.get<QuestionRankingItem[]>("/dashboard/rankings/questions", { params: { range: `${rangeDays}d` } }).then(r => r.data),

    api.get<ResponseTimeStatsBucket[]>("/dashboard/stats/response-time", { params: { range: `${rangeDays}d` } }).then(r => r.data),
};
