## 1. 文档说明

### 1.1 范围
实现 JWT 登录、Token 校验、当前用户注入（`get_current_user`）和 RBAC 操作权限拦截。其他模块的 Router 通过依赖 `CurrentUserDep` + `require_permission` 实现鉴权。

### 1.2 依据
- 《知识库管理平台 PRD V1.0》§2.9.2 角色定义、§2.9.3 登录与个人中心、§2.9.4 操作权限规则
- 《概要设计总纲 V1.0》§2 技术选型、§5.1 关键流程
- 《数据对象文档 V1.0》§2.1 users、§2.3 roles、§2.4 user_roles、§2.5 role_permissions
- 《接口约定文档 V1.0》§2 认证、§7.1 认证 / 个人中心

### 1.3 非目标
- 第三方 IdP 接入（OAuth / SSO / LDAP）
- 双因素认证（MFA）
- 密码找回自助流程（仅管理员重置）
- 设备指纹与会话并发控制

```python
@router.post("/logout", status_code=204)

```

### 5.2 Service（`app/services/auth_service.py`）

```python
class AuthService:
    def __init__(
        self,
        auth_repo: AuthRepositoryDep,
        password_hasher: PasswordHasherDep,
        jwt_issuer: JWTIssuerDep,
        redis: RedisDep,
    ): ...

    async def login(self, username: str, password: str) -> LoginResponse:
        """登录流程：查用户 → 验密码 → 加载角色与权限 → 签发 JWT → 写 Redis 位图 → 返回"""
        user = await self._auth_repo.find_by_username(username)
        if user is None or user.status != 1:
            raise AuthenticationError("invalid_credentials")
        if not self._password_hasher.verify(password, user.password_hash):
            raise AuthenticationError("invalid_credentials")
        role_codes = await self._auth_repo.list_role_codes(user.id)
        permissions = await self._auth_repo.list_permissions(role_codes)
        access_token, expires_in = self._jwt_issuer.issue(user.id, username, role_codes)
        await self._redis.set_bitmap(user.id, permissions, ttl=300)
        return LoginResponse(...)

    async def me(self, user: CurrentUser) -> MeResponse:
        """返回当前用户信息与权限（鉴权位图优先，缺失则重算）"""
        permissions = await self._redis.get_bitmap(user.id) or await self._recompute_permissions(user)
        return MeResponse(user_info=user.info, permissions=permissions)

    async def logout(self, user_id: int) -> None:
        """清除鉴权位图缓存；Token 本身因无状态不强制失效"""
        await self._redis.del_bitmap(user_id)
```

### 5.5 依赖注入（`app/api/dependencies.py`）

```python
async def get_current_user(
    credentials: Annotated[HTTPAuthorizationCredentials | None, Depends(HTTPBearer(auto_error=False))],
    jwt_issuer: JWTIssuerDep,
    auth_service: AuthServiceDep,
) -> CurrentUser:
    if credentials is None:
        raise AuthenticationRequiredError()
    try:
        payload = jwt_issuer.verify(credentials.credentials)
    except JWTError as exc:
        raise InvalidAccessTokenError() from exc
    return await auth_service.load_current_user(payload.sub)

CurrentUserDep = Annotated[CurrentUser, Depends(get_current_user)]

def require_permission(*codes: str) -> Callable:
    async def checker(user: CurrentUserDep, redis: RedisDep) -> None:
        permissions = await redis.get_bitmap(user.id)
        if not any(c in (permissions or []) for c in codes):
            raise PermissionDeniedError(missing=codes)
    return Depends(checker)
```

### 5.6 异常

```python
class AuthenticationRequiredError(AuthenticationError):
    error_code = "authentication_required"

class InvalidAccessTokenError(AuthenticationError):
    error_code = "invalid_access_token"

class InvalidCredentialsError(AuthenticationError):
    error_code = "invalid_credentials"

class UserDisabledError(PermissionDeniedError):
    error_code = "user_disabled"
```

### 6.3 状态

| --- | --- | --- |
| 登录中 | submit | 按钮 loading，输入禁用 |
| 凭据错误 | 401 + `invalid_credentials` | 输入框红色 + "用户名或密码错误" |

| 权限缺失 | 403 + `permission_denied` | 全局提示条 + 关闭当前操作 |

## 7. OpenAPI 接口契约

### 7.1 POST /api/v1/auth/login

**权限**：公开

**请求**：
```json
{ "username": "admin", "password": "admin123" }
```

**响应 200**：
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_in": 28800,
  "user_info": {
    "id": 1,
    "username": "admin",
    "display_name": "系统管理员",
    "department_id": 1,
    "department_name": "研发中心",
    "role_codes": ["system_admin"]
  },
  "permissions": [
    "user:read", "user:write", "role:read", "role:write",
    "dept:read", "dept:write",
    "knowledge:read", "knowledge:write", "knowledge:delete",
    "ai:chat", "dashboard:read",
    "faq:read", "faq:write", "faq:review",
    "gap:read"
  ]
}
```

**错误**：
| 状态码 | error_code | 触发条件 |
| --- | --- | --- |
| 401 | invalid_credentials | 用户名不存在或密码错误 |
| 403 | user_disabled | 账号 status=0 |
| 422 | validation_failed | username/password 不符合长度约束 |

### 7.2 GET /api/v1/auth/me

**权限**：需登录

**响应 200**：同 login 的 user_info + permissions（位图优先）

### 7.3 POST /api/v1/auth/logout

**权限**：需登录

**响应 204**（前端同步清 localStorage）

## 8. 异步与适配器

| 项 | 描述 |
| --- | --- |
| JWT 算法 | HS256 |
| Token 有效期 | 8 小时（`settings.jwt_expire_minutes=480`） |
| 密码哈希 | bcrypt cost=12 |
| Redis 键 | `auth:bitmap:{user_id}` → JSON 数组 `["perm1", "perm2"]`，TTL 300 秒 |
| 权限变更主动失效 | M2 修改角色权限时 `DEL auth:bitmap:{user_id}` |

## 9. 权限、审计与日志

### 9.1 数据范围

`/me` 与 `/login` 响应只返回当前用户自身字段，不返回其他用户信息。

### 9.2 关键事件日志

| 事件 | 字段 |
| --- | --- |
| 登录成功 | log:info `event=auth.login.success user_id=... username=...` |
| 登录失败 | log:warn `event=auth.login.fail username=... ip=... reason=...` |
| 登出 | log:info `event=auth.logout user_id=...` |
| Token 失效 | log:warn `event=auth.token.invalid path=... ip=...` |

### 9.3 脱敏
- 日志不记录完整 Token，仅记 user_id
- 密码字段永不入日志
