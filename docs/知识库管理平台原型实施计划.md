# 知识库管理平台原型实施计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `subagent-driven-development`（推荐）或 `executing-plans` 逐任务实施本计划。步骤使用复选框跟踪进度。

**目标：** 使用 Pencil 创建覆盖完整桌面端、完整移动端和关键业务状态的知识库管理平台高保真原型，并将可编辑 `.pen` 文件与预览图输出到项目 `docs` 目录。

**架构：** 原型采用“统一管理台 + 沉浸式 AI 工作台”。先建立设计变量与复用组件，再按桌面端、移动端、关键状态分批创建顶层页面 Frame，最后执行结构检查、视觉检查和导出。

**技术栈：** Pencil `.pen` 2.17、Pencil execute API、Manrope、Noto Sans SC、IBM Plex Mono、Lucide Icons。

---

## 文件结构

- 创建：`docs/知识库管理平台原型.pen` — 可编辑原型源文件。
- 创建：`docs/知识库管理平台原型预览/` — 桌面端与移动端关键页面 PNG 预览。
- 使用：`docs/知识库管理平台原型设计说明.md` — 已批准的设计规格。
- 使用：`docs/知识库管理平台需求.md` — 页面与业务能力依据。
- 使用：`docs/数据对象文档.md` — 表格字段、状态和示例实体依据。
- 使用：`docs/接口约定文档.md` — SSE、错误与权限状态依据。

## 任务 4：创建桌面端知识资产页面

- [ ] 创建知识导入中心：拖拽区、格式/大小规则、上传队列和文件级解析状态。

- [ ] 创建知识单元列表：编号、标题、分类、格式、权限摘要、创建人、更新时间、状态、批量删除。

## 任务 5：创建桌面端 AI 鉴权工作台

- [ ] 创建三段式工作台：会话列表、对话主区、知识引用与鉴权侧栏。
- [ ] 创建用户提问、流式回复、标准 FAQ 缓存命中三种消息状态。
