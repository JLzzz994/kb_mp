## 1. 路径与版本

- 所有业务接口前缀 `/api/v1/...`
- 路径用复数名词 + 小写连字符：`/api/v1/knowledge-units`
- 资源动作通过 HTTP method + 子路径表达，避免动词入路径
- 集合操作 vs 单资源：

| 场景 | Method | 路径 |
| --- | --- | --- |
| 列表 | GET | `/api/v1/<resources>` |
| 详情 | GET | `/api/v1/<resources>/{id}` |
| 创建 | POST | `/api/v1/<resources>` |
| 全量更新 | PUT | `/api/v1/<resources>/{id}` |
| 部分更新 | PATCH | `/api/v1/<resources>/{id}` |
| 删除 | DELETE | `/api/v1/<resources>/{id}` |
| 批量操作 | POST | `/api/v1/<resources>/batch` |
| 子资源动作 | POST | `/api/v1/<resources>/{id}/<action>` |

## 2. 认证

### 2.1 JWT Bearer

```
Authorization: Bearer <access_token>
```

- 登录后服务端签发 JWT，HS256 + `settings.jwt_secret`
- Claims：`sub=user_id`、`username`、`iat`、`exp`（默认 8h）
- HTTPBearer 依赖（`app/api/dependencies.py`）：

```python
async def get_current_user(token: Annotated[str, Depends(HTTPBearer())]) -> CurrentUser:
    ...
CurrentUserDep = Annotated[CurrentUser, Depends(get_current_user)]
```

- 401 走全局 handler，不在 Router 内抛 HTTPException

### 2.2 公开接口

仅以下接口无需 Token：

| Method | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/auth/login` | 登录 |
| GET | `/health` | 健康检查 |

### 2.5 权限码约定

| 权限码分类 | 权限码 | 说明 |
| --- | --- | --- |
| 知识鉴权查询 | `knowledge:check` | 鉴权接口（AI 内部 + 前端调试） |
| 知识权限分配 | `knowledge:assign_permission` | 配置四维数据权限（仅知识管理员） |

**权限码移除记录**：
- `gap:write`（原计划用于知识缺口侧写权限）：当前所有知识缺口相关接口已使用 `knowledge:write`，`gap:write` 无接口依赖。决定：**从 PermissionCode 列表与 ALL_PERMISSION_CODES 中删除**（H4 决议）。

## 3. 请求约定

### 3.1 请求头

| 头 | 必填 | 说明 |
| --- | --- | --- |
| Authorization | 是（除公开接口） | `Bearer <token>` |
| Content-Type | POST/PUT/PATCH | `application/json` |
| Content-Type | 文件上传 | `multipart/form-data` |
| X-Request-Id | 否 | 客户端生成，用于链路追踪 |

### 3.2 Query 参数

- 列表分页：`page`（≥ 1）、`page_size`（1 ≤ ≤ 100）
- 筛选：单词 `status` / `category` / `keyword` 全部用 query，不入 body
- 排序：`sort` 形如 `-created_at`（前缀 `-` 倒序），不传则用默认

### 3.3 Body

- JSON object；不接收顶层数组（避免 CSRF 与日志噪声）
- 字段名 snake_case
- 时间字段 ISO 8601 字符串（`2026-08-18T15:30:00+08:00`）
- 时间字段进数据库前转换为 UTC

### 3.4 文件上传

- 字段名 `files`，可多文件
- 类型：`UploadFile = File(...)`
- 服务端按 `content_type` + 扩展名双重校验
- 大小限制：单文件 20MB，批量总大小 200MB（通过 `request.headers["content-length"]` 提前拦截）

## 4. 响应约定

### 4.1 成功响应

FastAPI 原生（**不**额外包 `{code, message, data}`）：

```json
{
  "id": 123,
  "title": "...",
  "created_at": "2026-08-18T15:30:00+08:00"
}
```

### 4.2 列表分页响应

```json
{
  "items": [...],
  "page": 1,
  "page_size": 20,
  "total": 137
}
```

Pydantic 泛型：

```python
class Page(BaseModel, Generic[T]):
    items: list[T]
    page: int
    page_size: int
    total: int
```

### 4.3 创建响应

`POST` 成功返回 201 + 资源对象（不返回 `{id: ...}` 简版）。

### 4.4 删除响应

`DELETE` 成功返回 204 No Content。

## 5. 错误格式

### 5.1 错误响应体

```json
{
  "detail": "knowledge unit not found",
  "error_code": "resource_not_found",
  "request_id": "5e9b1d2c-aaaa-bbbb-cccc-dddddddddddd"
}
```

- `detail`：人类可读消息（中文）
- `error_code`：机器可读短码（snake_case）
- `request_id`：链路追踪 id

### 5.2 HTTP 状态码

| 码 | 含义 | error_code 范例 |
| --- | --- | --- |
| 400 | 请求格式错误 | `bad_request` |
| 401 | 身份无效 | `authentication_required` / `invalid_access_token` |
| 401 | Authorization 头缺失 | `authentication_required` |
| 401 | Token 过期 / 签名错误 / 用户被停用 | `invalid_access_token` |
| 403 | 身份有效但无权限 | `permission_denied` |
| 404 | 资源不存在 | `resource_not_found` |
| 409 | 资源冲突 | `resource_conflict` |
| 422 | 参数校验失败 | `validation_failed` |
| 429 | 限流 | `rate_limited` |
| 500 | 服务器内部错误 | `internal_error` |

**统一权限拦截**：

| 状态码 | error_code | 触发条件 |
| --- | --- | --- |
| 403 | `permission_denied` | 所有 Router 通过 `require_permission` 拦截统一返回，data 含缺失权限码列表 |
| 401 | `authentication_required` | 未携带 Bearer Token |
| 401 | `invalid_access_token` | Token 过期 / 签名错误 |

**知识导入业务错误码**（`POST /api/v1/knowledge/import`）：

| 状态码 | error_code | 触发条件 |
| --- | --- | --- |
| 409 | `content_duplicate` | SHA-256 内容哈希命中已存在单元 |
| 413 | `file_too_large` | 单文件 > 20MB 或批量 > 200MB |
| 415 | `unsupported_media_type` | 扩展名 / Content-Type 不在白名单（pdf/md/docx/txt） |

### 5.3 业务异常体系

`app/common/errors.py` 已定义基础类，业务模块按需扩展：

```python
class KnowledgeUnitNotFoundError(ResourceNotFoundError):
    error_code = "knowledge_unit_not_found"

class KnowledgeUnitDuplicateError(ValidationError): error_code = "content_duplicate"
class FileTooLargeError(ValidationError): error_code = "file_too_large"
class UnsupportedMediaTypeError(ValidationError): error_code = "unsupported_media_type"
```

Router 内不直接抛 HTTPException；Service / Repository 抛业务异常，全局 handler 统一映射。

### 5.4 全局 Handler

```python
@app.exception_handler(AppError)
async def app_error_handler(request, exc: AppError):
    return JSONResponse(
        status_code=exc.status_code,
        content={
            "detail": str(exc),
            "error_code": exc.error_code,
            "request_id": request.state.request_id,
        },
    )
```

## 6. 流式（SSE）— AI 问答

`POST /api/v1/ai/chat/stream` 返回 `text/event-stream`：

### 6.1 事件类型

| 事件 | data 字段 | 说明 |
| --- | --- | --- |
| `ready` | `{ "session_id": "..." }` | 服务端准备就绪 |
| `progress` | `{ "step": "retrieve", "progress": 0.4 }` | 阶段进度（可选） |
| `delta` | `{ "text": "部分内容" }` | 流式文本片段 |
| `citation` | `{ "unit_id": 123, "title": "...", "score": 0.82 }` | 知识引用（鉴权后、生成前回流） |
| `unauthorized` | `{ "unit_ids": [{"id": 88, "score": 0.65}, {"id": 92, "score": 0.42}] }` | 召回但无权访问的单元（对象数组，与 citation 对齐） |
| `interrupt` | `{ "reason": "no_recall_with_permission", "session_id": "..." }` | 召回为空或鉴权后无单元；写 `pending_turn` 等待用户重述 |
| `final` | `{ "answer": "...", "usage": {"prompt_tokens": 312, "completion_tokens": 148, "total_tokens": 460}, "response_time_ms": 2341 }` | 收尾；`response_time_ms` 与 `usage` 同级，不嵌入 |
| `error` | `{ "error_code": "...", "detail": "..." }` | 出错 |

**事件触发顺序**（典型一次问答）：
```
ready → (progress 多个) → (delta 多个) → (citation 多个) → (unauthorized ?) → final
```
- unauthorized 事件在 citation 之后、final 之前
- interrupt 事件替代 final
- error 事件可发生在任意阶段

`interrupt` 触发条件（任一）：
- 鉴权后 `authorized_units` 为空
- `recall` 召回列表为空
- 召回相似度低于动态断崖阈值（Top-1 < 0.2 等极端情况）

收到 `interrupt` 后，前端展示"未找到相关知识"提示并保留输入框；用户补充提问后调用 `POST /api/v1/ai/chat/resume` 续接。

**SSE error 事件 error_code 命名空间**（与 HTTP 错误码隔离）：
- HTTP 阶段（401/403/404/422）→ 走 §5.2 通用错误响应体
- SSE error 事件 → 仅承载流内业务错误：
  - `llm_timeout`
  - `llm_unavailable`
  - `vector_unavailable`
  - `recall_empty_unexpected`
  - `prompt_assembly_failed`

> HTTP 错误码与 SSE error 事件 error_code 完全分离，前端需根据响应阶段（HTTP vs SSE）选用不同解析路径。

### 6.2 客户端用法（伪代码）

```javascript
const es = new EventSource('/api/v1/ai/chat/stream?session_id=...&question=...')
es.addEventListener('delta', e => appendText(JSON.parse(e.data).text))
es.addEventListener('final', e => { es.close(); finish(JSON.parse(e.data)) })
es.addEventListener('error', e => { es.close(); showError(e) })
```

### 6.3 客户端鉴权

`EventSource` 不支持自定义 header，前端用 `fetch + ReadableStream` 替代：

```javascript
const resp = await fetch('/api/v1/ai/chat/stream', {
  method: 'POST',
  headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({ session_id, question }),
})
const reader = resp.body.getReader()
const decoder = new TextDecoder()
while (true) {
  const { done, value } = await reader.read()
  if (done) break
  for (const event of parseSSE(decoder.decode(value))) handle(event)
}
```

  - 关闭 `/docs` `/redoc`（`FastAPI(docs_url=None, redoc_url=None)`）
  - 通过环境变量 `APP_ENV=production` 切换
- `openapi.json` 始终可用（供前端 codegen 与运维）

### 9.1 自定义 OpenAPI 字段

`app/api/app.py` 中通过 `app.openapi = custom_openapi` 注入：

- `info.title` / `info.version` / `info.description`
- `servers`：单环境只配 base URL
- `tags` 分组：与上文接口分组对应

## 11. 与前端协作约定

- 前端通过 `frontend/src/api/` 下每个模块一个 `xxx.ts` 集中封装 axios 调用
- Token 存储在 localStorage（演示），axios 拦截器自动注入 header
- 401 响应：拦截器清 token + 跳登录
- 流式接口使用 `fetch + ReadableStream`（见 §6.3）
- 类型生成：可选用 `openapi-typescript-codegen` 从 `/openapi.json` 生成 TS 类型
