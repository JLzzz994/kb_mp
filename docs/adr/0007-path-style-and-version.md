# ADR-0007: API 路径风格与版本前缀冻结

## 状态
已决定 (2026-08-19)

## 背景
需求原文档使用 `/api/...` 路径 + 单数嵌套；接口约定文档统一为 `/api/v1/...` + 连字符复数 + settlement 域下沉。跨文档不一致。

## 决策
- 所有业务接口固定前缀：`/api/v1/`
- 资源路径风格：复数名词 + 连字符（`/knowledge-units` 而非 `/knowledge/units`）
- 沉淀域路由：下沉到 `/faqs` + `/knowledge-gaps`（不再保留 `/settlement` 命名）
- 更新操作：`PATCH` 用于部分更新、`PUT` 用于全量替换

## 影响
- PRD §6、需求 §2.9.8 全部同步
- 接口约定文档已是 v1 标准
- 前端代码生成器按 v1 模式

## 备选方案
- 保留 `/api/settlement/` 命名（与 PRD 一致）—— 拒绝
- 用 `/api/org-units` 替代复数（与 RFC 风格冲突）—— 拒绝
