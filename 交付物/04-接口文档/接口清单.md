# kb_mp 接口约定（43 端点全量）

## 0. 全局约定

| 项 | 值 |
|---|---|
| 基础路径 | `/api/v1` |
| 数据格式 | JSON（`application/json`） |
| 鉴权 | 除 `/auth/login` / `/health` 外，全部需 `Authorization: Bearer <token>` |
| 鉴权头 | `Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...` |
| 时区 | 数据库 UTC，API 响应 ISO 8601（`2026-08-19T15:30:00Z`） |
| 分页 | 默认 `page=1&page_size=20`，最大 page_size=100 |
| 错误响应 | `{"code": "forbidden", "message": "权限不足"}`（HTTP 400-500） |

## 1. 健康检查（1 端点）

### `GET /health`

无需鉴权。

**响应**（200）：
```json
{
  "status": "ok",
  "service": "kb-mp",
  "version": "0.1.0"
}
```

## 2. 鉴权域（3 端点）

公开。

```json
  "password": "Admin@123"
}
```

**响应**（200）：
```json

  "token_type": "bearer",
  "expires_in": 28800,
  "user_info": {
    "id": 1,
    "username": "admin",
    "display_name": "系统管理员",
    "department_id": 1,
    "department_name": "研发中心",
    "role_codes": ["system_admin"]
  },
  "permissions": ["user:read", "user:write", "role:read", "role:write", "dept:read", "dept:write", "knowledge:read", "knowledge:write", "knowledge:delete", "knowledge:assign_permission", "knowledge:check", "ai:chat", "dashboard:read", "faq:read", "faq:write", "faq:review", "gap:read"]
}
```

### `GET /auth/me`

需鉴权。

**响应**（200）：
```json
{
  "user_info": {
    "id": 1,
    "username": "admin",
    "display_name": "系统管理员",
    "department_id": 1,
    "department_name": "研发中心",
    "role_codes": ["system_admin"]
  },
  "permissions": ["user:read", ...]
}
```

### `POST /auth/logout`

需鉴权。清 Redis 鉴权位图。

**响应**（204 No Content）

## 3. 组织架构域（11 端点）

### 部门管理（4 端点）

#### `GET /org/departments`
需 `dept:read`。

**响应**：
```json
[
  {"id": 1, "parent_id": null, "name": "研发中心", "leader_id": null, "sort_order": 0, "children": []},
  {"id": 2, "parent_id": null, "name": "产品部", "leader_id": null, "sort_order": 1, "children": []}
]
```

#### `POST /org/departments`
需 `dept:write`。

```json
{"name": "新部门", "parent_id": 1, "sort_order": 5}
```

#### `PUT /org/departments/{dept_id}`
需 `dept:write`。

```json
{"name": "更新名", "parent_id": null, "sort_order": 10}
```

#### `DELETE /org/departments/{dept_id}`
需 `dept:write`。

响应 204。如有子部门或成员，返回 422 `department_not_empty`。

### 角色管理（3 端点）

#### `GET /org/roles`
需 `role:read`。

```json
[
  {"id": 1, "role_code": "system_admin", "role_name": "系统管理员", "description": "...", "permissions": ["user:read", ...]},
  ...
]
```

#### `GET /org/permissions`
需 `role:read`。返回 17 权限码白名单。

#### `POST /org/roles/{role_id}/permissions`
需 `role:write`。

```json
{"permission_codes": ["knowledge:read", "ai:chat"]}
```

### 用户管理（5 端点）

#### `GET /org/users?page=1&page_size=20&keyword=alice`
需 `user:read`。

```json
{"total": 3, "items": [{"id": 3, "username": "alice", "display_name": "Alice", "department_id": 2, "status": 1, "role_codes": ["regular_user"]}]}
```

#### `GET /org/users/{user_id}`
需 `user:read`。

#### `POST /org/users`
需 `user:write`。

```json
{"username": "bob", "password": "Bob@123", "display_name": "Bob", "department_id": 1, "role_codes": ["knowledge_admin"]}
```

#### `PUT /org/users/{user_id}`
需 `user:write`。

#### `PATCH /org/users/{user_id}/status`
需 `user:write`。

```json
{"status": 0}
```

#### `POST /org/users/{user_id}/reset-password`
需 `user:write`。重置为临时密码 `Kb@12345`。

## 4. 知识资产域（7 端点）

### `POST /knowledge/import`

需 `knowledge:write`。多文件上传。

```bash
curl -X POST http://localhost:8000/api/v1/knowledge/import \
  -H "Authorization: Bearer $TOKEN" \
  -F "files=@01-kb_mp-平台介绍.md" \
  -F "files=@02-kb_mp-部署指南.md"
```

**响应**（202）：
```json
{
  "accepted_count": 2,
  "task_ids": ["imp-xxx", "imp-yyy"]
}
```

### `GET /knowledge-units?page=1&page_size=20&category=产品`

需 `knowledge:read`。

```json
{
  "total": 5,
  "items": [
    {"id": 1, "unit_code": "KU-001", "title": "kb_mp 平台介绍", "category": "产品", "status": "active", "creator_id": 1, "created_at": "2026-08-19T15:00:00Z"}
  ]
}
```

### `GET /knowledge-units/{unit_id}`

需 `knowledge:read`。

```json
{
  "id": 1,
  "unit_code": "KU-001",
  "title": "kb_mp 平台介绍",
  "content": "完整正文...",
  "summary": "...",
  "category": "产品",
  "status": "active",
  "permissions": [
    {"target_type": "global", "target_id": null}
  ],
  "creator_id": 1,
  "created_at": "2026-08-19T15:00:00Z",
  "updated_at": "2026-08-19T15:00:00Z"
}
```

### `PATCH /knowledge-units/{unit_id}`

需 `knowledge:write`。

```json
{"title": "新标题", "summary": "新摘要", "category": "新分类"}
```

### `DELETE /knowledge-units`

需 `knowledge:delete`。批量删除。

```json
{"unit_ids": [1, 2, 3]}
```

### `POST /knowledge-units/{unit_id}/permissions`

需 `knowledge:assign_permission`。四维权限全量替换。

```json
{
  "permissions": [
    {"target_type": "global", "target_id": null},
    {"target_type": "department", "target_id": 1},
    {"target_type": "role", "target_id": 2},
    {"target_type": "user", "target_id": 3}
  ]
}
```

### `POST /knowledge/check-permissions`

需 `knowledge:check`。鉴权检查（用户对哪些 unit 有访问权）。

```json
{
  "user_id": 3,
  "unit_ids": [1, 2, 3, 4]
}
```

**响应**：
```json
{
  "authorized": [1, 2, 4],
  "unauthorized": [3]
}
```

## 5. AI 对话域（7 端点）

### `POST /ai/sessions`

需 `ai:chat`。创建多轮会话。

```json
{"title": "AI 问答测试"}
```

### `GET /ai/sessions`

需 `ai:chat`。列出当前用户的会话（按 updated_at DESC）。

### `GET /ai/sessions/{session_id}`

需 `ai:chat`。

```json
{
  "id": "uuid-xxx",
  "title": "AI 问答测试",
  "history_json": {
    "messages": [
      {"role": "user", "content": "kb_mp 是什么？"},
      {"role": "assistant", "content": "kb_mp 是..."}
    ]
  },
  "created_at": "2026-08-19T15:00:00Z",
  "updated_at": "2026-08-19T15:01:00Z"
}
```

### `PATCH /ai/sessions/{session_id}`

需 `ai:chat`。重命名。

```json
{"title": "新标题"}
```

### `DELETE /ai/sessions/{session_id}`

需 `ai:chat`。

### `POST /ai/chat/stream`

需 `ai:chat`。**SSE 流式输出**。

```json
{"session_id": "uuid-xxx", "question": "kb_mp 是什么？"}
```

**SSE 事件流**：
```
event: ready
data: {"session_id": "uuid-xxx"}

event: progress
data: {"stage": "faq_cache_lookup", "progress": 10}

event: progress
data: {"stage": "retrieve", "progress": 30}

event: citation
data: {"units": [{"id": 1, "title": "kb_mp 平台介绍", "score": 0.92}]}

event: delta
data: {"chunk": "kb_mp"}

event: delta
data: {"chunk": " 是"}

event: final
data: {"answer": "kb_mp 是...", "tokens": {"prompt": 100, "completion": 50, "total": 150}}
```

可能事件：`ready` / `progress` / `citation` / `unauthorized` / `interrupt` / `delta` / `final` / `error`

### `POST /ai/chat/resume`

需 `ai:chat`。中断恢复（interrupt 触发后用户补充信息）。

```json
{"session_id": "uuid-xxx", "interrupt_id": "int-xxx", "additional_info": "用户补充"}
```

### `DELETE /faqs/{faq_id}`

需 `faq:write`。

### `GET /knowledge-gaps?status=unresolved&page=1&page_size=20`

需 `gap:read`。

```json
{
  "total": 3,
  "items": [
    {"id": 1, "question_pattern": "kb_mp 如何部署？", "ask_count": 5, "status": "unresolved", "sample_questions": ["怎么部署？", "如何启动？"]}
```

```json
{"initial_content": "初始内容（可选）"}
```

```json
{"unit_id": 6, "status": "pending"}
```

## 8. 通用错误码

| HTTP | code | 含义 |
|---|---|---|
| 400 | invalid_request | 参数校验失败 |
| 401 | unauthenticated | JWT 无效 / 过期 |
| 403 | forbidden | 无权限码 |
| 404 | not_found | 资源不存在 |
| 409 | conflict | 资源冲突（如重复） |
| 422 | business_rule_violated | 业务规则违反 |
| 500 | internal_error | 服务器异常 |
