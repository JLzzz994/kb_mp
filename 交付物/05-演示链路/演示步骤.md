## 二、详细步骤

### 步骤 0：环境准备

```bash
# 后端（首次）
cd 交付物/02-数据库初始化
bash init_db.sh    # macOS / Linux
init_db.bat        # Windows

# 启动后端
cd 交付物/01-启动脚本
bash 启动后端.sh &

# 启动前端
bash 启动前端.sh &

# 浏览器访问
open http://localhost:5173
```

### 步骤 1：admin 登录

打开浏览器 → http://localhost:5173 → 自动跳转 `/login`

**手动登录**：

```bash
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"Admin@123"}'
```

**预期响应**：
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expires_in": 28800,
  "user_info": {
    "username": "admin",
    "display_name": "系统管理员",
    "role_codes": ["system_admin"]
  },
  "permissions": ["user:read", "user:write", "role:read", "role:write", ...]  # 17 个
}
```

**前端体现**：登录后侧栏显示 7 大模块菜单（仪表盘 / ��识资产 / AI 工作台 / FAQ / 知识缺口 / 组织管理 / 系统设置）

### 步骤 2：上传示例文档

```bash
TOKEN=<上一步拿到的 token>

curl -X POST http://localhost:8000/api/v1/knowledge/import \
  -H "Authorization: Bearer $TOKEN" \
  -F "files=@03-示例数据/01-kb_mp-平台介绍.md" \
  -F "files=@03-示例数据/02-kb_mp-部署指南.md" \
  -F "files=@03-示例数据/03-研发中心技术规范.md" \
  -F "files=@03-示例数据/04-FAQ清单.md"
```

**预期响应**（202）：
```json
{"accepted_count": 4, "task_ids": [...]}
```

**前端体现**：进入"知识导入中心"页面，看到 4 条 accepted 记录。后台异步向量化（3-10 秒），Milvus 中可检索。

### 步骤 3：AI 问答 - 命中 KU-001

打开 AI 对话工作台 → 输入 "kb_mp 平台是什么？"

**SSE 流**：
```
event: ready
event: progress {"stage": "faq_cache_lookup", "progress": 10}
event: progress {"stage": "retrieve", "progress": 30}
event: citation {"units": [{"id": 1, "title": "kb_mp 平台介绍", "score": 0.92}]}
event: progress {"stage": "permission_filter", "progress": 50}
event: progress {"stage": "assemble_prompt", "progress": 70}
event: progress {"stage": "generate", "progress": 80}
event: delta {"chunk": "kb_mp"}
event: delta {"chunk": " 是"}
event: delta {"chunk": " 企业"}
... （流式打字效果）
event: final {"answer": "kb_mp 是...", "tokens": {...}}
```

**前端体现**：
- 左侧 SSE 进度徽章链（8 节点逐一高亮）
- 中间打字光标（流式输出）
- 右上"引用"卡片（点击展开 KU-001 详情）

### 步骤 4：AI 问答 - 命中 KU-002

输入 "如何部署 kb_mp？"

**预期**：召回 KU-002，答案为部署指南要点。

### 步骤 5：AI 问答 - 触发 interrupt

输入 "完全不相关的问题比如今天天气怎么样"

**预期流**：
```
event: ready
event: progress {"stage": "faq_cache_lookup", "progress": 10}
event: progress {"stage": "retrieve", "progress": 30}
event: progress {"stage": "permission_filter", "progress": 50}
event: interrupt {"interrupt_id": "int-xxx", "reason": "no_recall", "message": "未找到相关内容"}
```

**前端体现**：弹出补充输入框 "请补充关键词或描述"。

### 步骤 6：alice 登录 - 鉴权拦截演示

**登出 admin → 登录 alice**（alice 是运营部普通用户，仅 4 权限）

输入 "研发中心技术规范有哪些内容？"

**预期流**：
```
event: ready
event: progress {"stage": "retrieve", "progress": 30}
event: citation {"units": [{"id": 3, "title": "研发中心技术规范", "score": 0.88}]}
event: unauthorized {"unit_ids": [3]}
event: interrupt {"interrupt_id": "int-yyy", "reason": "no_authorized_recall", "message": "命中但未授权"}
```

**前端体现**：告知用户"此内容未对您授权"。

### 步骤 7：数据看板

进入"数据看板"页面：

- **指标卡**（5 张）：总问答数 / 知识单元数 / FAQ 命中率 / 平均响应时间 / Token 总用量
- **趋势图**：问答量趋势（24h / 7d / 30d / 90d）
- **Top-10 排行**：高频问题 / 高贡献单元
- **性能图**：Token 用量 / 响应时间分桶

**实测**：跑完前面演示后，看板会显示真实问答数据。

### 步骤 8：FAQ 创建 + 审核

```bash
# 创建 FAQ
curl -X POST http://localhost:8000/api/v1/faqs \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "FAQ 测试问题",
    "answer": "标准答案内容",
    "category": "测试",
    "source_type": "manual"
  }'

# 审核（admin）
curl -X POST http://localhost:8000/api/v1/faqs/1/review \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "approve"}'
```

### 步骤 9：知识缺口识别 + 一键建档

多次提问同一问题模式 → 系统自动识别为 gap：

```bash
# 查看缺口
curl http://localhost:8000/api/v1/knowledge-gaps?status=unresolved \
  -H "Authorization: Bearer $TOKEN"

# 一键建档
curl -X POST http://localhost:8000/api/v1/knowledge-gaps/1/create-unit \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"initial_content": "针对该问题的标准答案"}'
```

**预期响应**：
```json
{"unit_id": 6, "status": "pending"}
```

**前端体现**：知识缺口列表 → 点击"一键建档" → 自动跳转到新建知识单元编辑页。
